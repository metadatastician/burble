= scripts — operational helpers
:toc: preamble

== Purpose

Operator/maintainer scripts for deployment, Bolt reachability, and build
prerequisites. None are required for `just deploy`; they support
specific deployment topologies.

== Contents

*Bolt reachability:*
`cf-bolt-dns.sh`, `cf-ddns.sh`, `cf-worker-deploy.sh`:: Cloudflare NAPTR/
SRV + DDNS provisioning and worker deploy for public Bolt reach.
`gen-bolt-cert.sh`:: Ed25519/P-256 self-signed cert for Bolt-over-QUIC
(ADR-0004).
`check-bolt-reachability.sh`:: Verify udp/7373 is reachable end-to-end.
`mikrotik-bolt-nat.sh`:: Router dst-NAT rule for udp/7373.
`wsl-bolt-udp-forward.ps1`:: Windows-host UDP forwarder for running the
Bolt listener under WSL2 without mirrored networking (ADR-0005).

*Build / deploy:*
`ensure-msquic-version.sh`, `ensure-quicer-prereqs.sh`:: Guard the
optional QUIC toolchain (msquic/quicer; experimental — ADR-0007).
`docker-to-podman-image.sh`, `install-desktop.sh`, `smoke-check.sh`::
Deploy/build utilities.

*Verification:*
`check-elixir-syntax.mjs`:: Parse `server/lib` and `server/test` with the real
Elixir grammar (`tree-sitter-elixir`, WASM — no Elixir toolchain needed), and
optionally cross-check that every `Module.fun(args)` call names a function that
exists with that arity. It is a parser, not a compiler: it cannot resolve
macros, `use`-generated functions, protocols or behaviour callbacks, and it does
not type-check. Use it where `mix` is unavailable, never instead of `mix`.
Bun is the default runner (the script uses only `node:fs`, `node:path` and
`node:module`, so nothing about it is Deno-specific):

[source,bash]
----
cd scripts && bun install        # once; bun.lock is committed
bun run check:elixir             # == bun check-elixir-syntax.mjs ../server/lib ../server/test
----

From the repository root that is `bun run --cwd scripts check:elixir`. Measured
here on 2026-10-21: `parsed 208 file(s), 0 with parse errors`.

`scripts/package.json` and `scripts/bun.lock` pin both parser versions exactly.
`scripts/deno.json` and `scripts/deno.lock` are kept because the repository
template expects the manifest; they are not the documented way to run this. The
tool only uses the bundled WASM grammar, so native dependency build scripts are
not needed (Bun blocks the one postinstall it finds, and the tool runs anyway).
Rationale and measured results:
`docs/reports/maintenance/maintenance-2026-10-21.md` (Appendix).

`gen-e2ee-vectors.exs`:: Regenerate `client/web/tests/fixtures/e2ee-vectors.json`
from the shipped `Burble.Media.E2EE` functions (needs Elixir). Regenerate only
when the protocol changes — a changed value is a wire break.
`verify-e2ee-vectors.mjs`:: Re-derive those vectors with WebCrypto (X25519,
HKDF-SHA256, AES-256-GCM) — the primitives the browser half must use — and fail
on disagreement. No dependencies; runs on plain Node.

`burble-launcher.sh.deprecated-2026-04-10`:: Retained, deprecated.

== What this is, and how it works

Burble is a self-hostable voice platform. Its server is Elixir/Phoenix under
`server/`, its coprocessor kernels are Zig under `ffi/zig/`, an embeddable game
session client is Rust under `client/rust/`, and the ABI design is in Idris2
under `src/Burble/ABI/`. This file reports what those four toolchains said when
run against one commit on 2026-10-07. It reports runs, not intentions.

== The epistemic contract

You may conclude that each command below, run at the anchor commit with the
listed toolchain, produced the exit code and counts stated. You may not conclude
anything about other commits, about CI, about production deployments, or about
runtime conformance between the Idris2 model and the Zig/Elixir code. A green
type-check of the ABI is design assurance, not a proof that the running system
obeys it. No CI badge or CI run is cited as evidence here.

=== The honest nuance you must not lose

* *Compiles is not total.* Only `src/Burble/ABI.idr` carries `%default total`,
  and `burble-abi.ipkg` passes no `--total` option. The other 9 modules
  type-check without totality being enforced. "10/10 modules build" does not
  mean "10/10 modules are total".
* *Type-check is not conformance.* Nothing here checks that the Zig kernels or
  the Elixir server implement what the Idris2 ABI states.
* *Toolchain skew.* Local Zig was 0.16.0; `.github/workflows/elixir-ci.yml`
  pins Zig 0.15.2. A pass on 0.16.0 is not evidence for 0.15.2, or the reverse.
* *The 1 skipped ExUnit test* is still skipped; it was not exercised.
* *Vacuous guards.* `just test-server` first runs
  `scripts/ensure-msquic-version.sh` and `scripts/ensure-quicer-prereqs.sh`.
  Both exited 0 only because they skipped: `quicer` is commented out in
  `server/mix.exs` (line 211), so `server/deps/quicer` never exists. They
  checked nothing.
